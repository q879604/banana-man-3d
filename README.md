# 🍌 香蕉人 3D · 焦易轩

一个**纯静态、零外部依赖、可离线运行**的 3D 互动页面：打开就是一根长着大眼睛的香蕉人，
可以用手（或鼠标）任意拖动环绕观看、放大缩小，背景是流动的抽象极光。

**这一版是为焦易轩做的**：头顶悬浮一块跟着转的名字铭牌（刻着「焦易轩 / JIAO YI XUAN」），
左上角也写着送给谁，角色的眼睛还会一直跟着镜头看。

> **直接部署**：把整个文件夹原样丢到任意静态托管（Cloudflare Workers / GitHub Pages /
> Vercel / Nginx / 对象存储 / 甚至 U 盘）即可，不需要构建、不需要后端、不需要联网。

## 一、先跑起来

因为用了 ES module，**必须通过 HTTP 打开**（直接双击 `index.html` 走 `file://` 会被浏览器
的 CORS 策略拦住，页面会给出明确提示）。

```bash
# 在项目根目录执行任意一条
python3 -m http.server 8000      # Python
npx serve .                      # Node
php -S localhost:8000            # PHP
```

然后浏览器打开 <http://localhost:8000>。

| 平台 | 做法 |

## 三、怎么玩

| 操作 | 效果 |
| --- | --- |
| 单指拖动 / 鼠标左键拖动 | 环绕旋转，360° 随便看 |
| 滚轮 / 双指捏合 | 放大缩小 |
| **轻点角色** | 触发随机动作：跳一下 / 转一圈 / 软弹变形 |
| 移动鼠标 / 转动手机 | 它的眼珠会一直看着镜头（不是只跟着鼠标平移） |
| `空格` / 右下角「自转」 | 暂停或继续自动旋转 |
| `T` / 右下角「背景」 | 在 极光紫 / 落日粉 / 深海蓝 之间切换 |
| `R` / 右下角「复位」 | 视角回到初始位置 |
| `N` / 右下角「铭牌」 | 显示或隐藏头顶那块写着「焦易轩」的名字铭牌 |
| 右下角「截图」 | 把当前画面存成 PNG |

拖拽时会自动暂停自转，松手后继续；触摸设备上已屏蔽页面滚动与双指缩放冲突。

## 五、改造成自己的样子

### 1. 改体型
`src/banana.js` 顶部的 `CONFIG` 就是全部可调参数：

```js
bodyRadius: 0.44,   // 香蕉胖瘦
curveP0/P1/P2,      // 香蕉弯曲程度（三个控制点）
ribAmp: 0.05,       // 表面纵棱深浅
taperTop: 0.46,     // 顶部收细程度
faceT: 0.72,        // 脸贴在香蕉的哪个高度（0 底 1 顶）
eyeRadius: 0.185,   // 眼睛大小
wobble: 1.0,        // 软弹动画强度，设 0 关闭
```

### 2. 改颜色
同文件里的 `PALETTE`：`peel` 香蕉皮色、`pupil` 瞳孔色、`blush` 腮红色……

### 3. 改背景主题
`src/scene.js` 里的 `THEMES`，每个主题六个色值（天穹四色 + 雾 + 网格 + 地面）+
三个灯光色。加一组就多一个主题，`T` 键能循环到。

### 4. 换掉角色
`createBananaMan()` 返回 `{ group, parts, update }`，`main.js` 只依赖这三个东西。
换成任意 glTF 模型也只要让 `update(time)` 去驱动动画即可。

## 六、实现要点

- **零外部资源**：没有贴图、没有字体、没有 CDN。所有几何是 three.js 参数化生成，
  背景光斑用 canvas 现画，天穹是手写 GLSL 的 fbm 噪声。
- **香蕉不是圆柱**：沿一条二次贝塞尔曲线扫掠截面，半径沿长度按
  `sin(πt)^0.62` 变化并叠加两端收细，截面半径再乘 `1 + 0.05·cos(5θ)`
  得到 5 条纵棱，所以有真实的香蕉弧度与棱线。
- **稳定的标架**：曲线在 XY 平面内，副法线恒取 +Z，于是 `θ = π/2` 永远正对镜头，
  眼睛、嘴巴、腮红、四肢都能按 `(t, θ)` 精确贴到体表。
- **软弹动画**在顶点着色器里做，越靠上摆幅越大，被点中时临时加大幅度。

## 七、兼容性

- Chrome / Edge 90+、Firefox 90+、Safari 15+、以及微信内置浏览器等现代内核；
- 需要 WebGL2（不支持时页面会显示可读的兜底说明，而不是白屏）；
- 已适配手机竖屏与平板，窄屏自动拉远视角并收起底部提示。
